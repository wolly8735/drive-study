# 🍽️ 오늘의 식단 분석

아침·점심·저녁 식단 사진을 올리면 AI(Claude)가 사진을 보고 **탄수화물 · 단백질 · 지방 · 칼로리**를
추정하고, 하루 목표 대비 부족하거나 과한 영양소를 알려주는 무료 웹앱입니다. 설치 없이
휴대폰 브라우저에서 바로 실행됩니다.

## 사용 방법

1. `index.html`을 정적 호스팅(예: GitHub Pages, Netlify, Vercel)에 올립니다.
2. 휴대폰/PC 브라우저로 배포된 주소에 접속합니다.
3. 화면 아래 **⚙️ API 키 / 목표 설정**을 열고 본인의 **Anthropic API 키**를 입력합니다.
   - [Anthropic 콘솔](https://console.anthropic.com/settings/keys)에서 무료로 발급받을 수 있습니다.
   - 사진 분석 1회당 소량의 API 비용(수 원~수십 원 수준)이 발생합니다. 비용을 아끼고 싶다면
     설정에서 분석 모델을 **Claude Haiku 4.5**로 바꿔보세요.
4. 아침/점심/저녁 카드에서 사진을 올리고 **분석하기**를 누르면 몇 초 후 결과가 표시됩니다.
5. 화면 상단 **오늘 합계** 카드에서 하루 전체 섭취량과 부족한 영양소에 대한 조언을 확인합니다.
6. 브라우저 메뉴에서 "홈 화면에 추가"를 하면 아이콘을 눌러 앱처럼 실행할 수 있습니다 (PWA).

## 동작 원리 & 개인정보

- 이 앱은 별도의 백엔드 서버가 없는 **순수 정적 웹앱**입니다.
- "분석하기"를 누르면 브라우저가 사진과 API 키를 **Anthropic API로 직접** 전송합니다.
  (`anthropic-dangerous-direct-browser-access` 헤더를 사용한 브라우저 직접 호출 방식)
- API 키는 이 기기의 브라우저 `localStorage`에만 저장되며, 앱 제작자를 포함해 그 누구도
  전송받거나 수집하지 않습니다. 다른 사람과 기기를 공유한다면 키를 지워주세요.
- 오늘 분석한 끼니별 영양 정보(사진 자체는 제외)는 하루 단위로 브라우저에 저장되어
  새로고침해도 유지되며, 자정이 지나면 새 날짜로 초기화됩니다.
- AI가 추정한 값은 **참고용 추정치**이며 실제 식품의 영양 성분과 차이가 있을 수 있습니다.

## 하루 목표치 설정하기

설정 패널의 **하루 목표치** 드롭다운에서 본인에게 맞는 기준을 선택하세요
(`data.js`의 `TARGET_PRESETS`에서 새 프리셋을 추가할 수도 있습니다):

- 일반 성인 (기본)
- 활동량 많은 성인 남성
- 성인 여성
- 체중 관리 / 다이어트
- 근성장 / 벌크업

각 끼니는 하루 목표의 30%(아침) / 40%(점심) / 30%(저녁) 비율로 나눠 끼니별 코멘트를 계산합니다
(`data.js`의 `MEAL_SHARE`).

## GitHub Pages로 배포하기

1. 저장소 Settings → Pages → Branch를 `main`(또는 배포 브랜치)의 루트로 설정합니다.
2. 몇 분 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속하면 됩니다.

## 주요 기능

- **사진 기반 AI 영양 분석**: Claude Vision에 사진을 보내 음식 이름과 칼로리/탄단지를 추정
- **끼니별 코멘트**: 각 끼니가 목표 대비 단백질이 부족한지 넉넉한지 바로 확인
- **하루 합계 & 조언**: 아침+점심+저녁을 합산해 하루 목표 대비 부족/과다 영양소를 안내
- **모델/목표 커스터마이징**: 분석 모델(Opus/Sonnet/Haiku)과 하루 목표치를 설정에서 변경 가능
- **PWA 지원**: 홈 화면 추가 시 앱처럼 실행, 서비스 워커로 앱 셸(화면 껍데기)만 캐싱
  (API 호출은 캐싱하지 않고 항상 실시간으로 분석합니다)

## 주의 사항

- 이 앱은 의학적 조언이 아닌 참고용 정보를 제공합니다. 정확한 영양 상담은 전문가와 상의하세요.
- 사진이 흐릿하거나 음식이 잘 보이지 않으면 추정 정확도가 떨어질 수 있습니다.
- API 키가 없거나 만료되면 분석이 실패합니다 — 이 경우 설정 화면의 오류 메시지를 확인해주세요.
