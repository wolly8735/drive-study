# 🚗 출근길 10분 섀도잉

출근길 10분 동안 영어·중국어·일본어·스페인어 핵심 단어와 문장을 소리로 듣고 따라 읽는
무료 섀도잉 학습 웹앱입니다. 설치 없이 인터넷만 되면 휴대폰 브라우저에서 바로 실행됩니다.

## 사용 방법

1. `index.html`을 정적 호스팅(예: GitHub Pages, Netlify, Vercel)에 올립니다.
2. 휴대폰 브라우저로 배포된 주소에 접속합니다.
3. **▶ 학습 시작하기** 버튼을 누르면 10분 분량의 4개 국어 섀도잉이 자동 재생됩니다.
   - 각 언어마다 "느리게 → 보통 속도 → 원어민 속도" 3단계로 들려주고,
     따라 말할 수 있도록 무음 구간을 둡니다.
4. 브라우저 메뉴에서 "홈 화면에 추가"를 하면 아이콘을 눌러 앱처럼 실행할 수 있습니다
   (PWA, 오프라인 재실행 지원).

음성은 브라우저 내장 TTS(Web Speech API)를 사용하므로 별도 서버 비용이나 로그인 없이
완전히 무료로 동작합니다. 음성 목소리는 기기/브라우저에 따라 달라질 수 있습니다.

## GitHub Pages로 배포하기

1. 저장소 Settings → Pages → Branch를 `main`(또는 배포 브랜치)의 루트로 설정합니다.
2. 몇 분 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속하면 됩니다.

## 학습일 추가하기

`data.js`의 `DAYS` 배열에 새로운 항목을 추가하면 자동으로 학습일 선택 드롭다운에
나타납니다. 각 언어별로 `introKo`(단어 소개), `sentence`(원문), `sentenceKo`(안내 멘트),
`reviewKo`(복습 멘트)만 채우면 재생 순서는 `app.js`의 `buildDaySequence()`가
자동으로 구성합니다.

```js
{
  id: 2,
  title: "2일차",
  intro: "...",
  outro: "...",
  languages: [
    { label: "영어", lang: "en-US", words: "...", introKo: "...", sentence: "...", sentenceKo: "...", reviewKo: "..." },
    // 중국어, 일본어, 스페인어 ...
  ],
  finalReview: "...",
}
```

## 주요 기능

- **자동 재생 엔진**: 안내 → 느린 발음 → 보통 속도 → 원어민 속도 → 복습 순서 자동 진행
- **이어서 재생**: 일시 정지 후 다시 누르면 멈춘 지점부터 이어서 재생 (처음부터 다시 X)
- **진행률 표시줄**: 오늘 학습이 얼마나 남았는지 한눈에 확인
- **연속 학습일(스트릭) 기록**: 완료할 때마다 로컬에 날짜를 저장해 "연속 N일" 표시
- **화면 꺼짐 방지**: Wake Lock API를 우선 사용하고, 이를 지원하지 않는 브라우저(구형
  iOS Safari, 카카오톡/네이버 인앱 브라우저 등)에서는 화면 밖에 숨긴 영상을 계속
  재생시켜 화면이 꺼지지 않도록 하는 보조 수단을 함께 사용합니다. 재생 중 앱을
  잠깐 벗어났다가 돌아와도 자동으로 다시 시도합니다.
- **PWA 지원**: 홈 화면 추가 시 앱 아이콘/독립 실행, 서비스 워커로 앱 셸 캐싱

## 주의 사항

- 반드시 안전한 곳에 휴대폰을 거치한 뒤 청취 위주로 사용하세요. 화면을 조작하며
  운전하지 않도록 재생 버튼 외 조작은 최소화했습니다.
- 일부 브라우저(특히 iOS Safari)는 절전 모드에서 백그라운드 음성 재생이 제한될 수
  있습니다. 화면을 켜둔 상태로 사용하는 것을 권장합니다.
- 화면 꺼짐 방지는 브라우저가 자동으로 화면을 끄는 것만 막아줍니다. 전원 버튼을
  눌러 직접 화면을 끄거나 잠그면 이 기능으로도 막을 수 없습니다.
